---
name: Multilingual search
description: Owner wants customers who type Russian or Transcarpathian dialect words to find products; how that was scoped
---
Owner chose "smart search + words for Google" over a full Russian site version (2026-10-29).
Owner-provided Transcarpathian words: коляска, памперси, цуцлик. Other dialect words in the list (смочок, забавка, ровер) were added by the agent as common western-Ukrainian words.
**Why:** product names come from the supplier only in Ukrainian; Google has no "Transcarpathian" language, so dialect reach = those words appearing on pages.
**How to apply:** when the owner names more local words, add them to the synonym list (dialect kind) — it drives both search and the visible SEO blocks. A Russian site version is a separate, bigger decision; Ukrainian must stay the default language by law.
