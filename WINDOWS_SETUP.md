# Запуск магазину «Пташеня» на Windows

Ці інструкції запускають магазин лише на вашому ПК для перевірки. Вони не відкривають сайт покупцям через інтернет.

## Потрібно встановити

1. Node.js 24 LTS: https://nodejs.org/
2. Git: https://git-scm.com/download/win
3. Visual Studio Code: https://code.visualstudio.com/
4. PostgreSQL: https://www.postgresql.org/download/windows/
5. У PowerShell встановити pnpm: `npm install --global pnpm@10`

Після встановлення закрийте й знову відкрийте VS Code та PowerShell.

## Завантажити код

1. У GitHub створіть приватний репозиторій.
2. У VS Code відкрийте командну палітру (`Ctrl+Shift+P`) і виберіть **Git: Clone**.
3. Вставте посилання на репозиторій і відкрийте завантажену папку.
4. У терміналі VS Code виконайте:

```powershell
pnpm install
Copy-Item .env.example .env
```

## Налаштувати локальну базу

У pgAdmin створіть порожню базу `ptashenya`. Відкрийте `.env` у VS Code і змініть пароль у `DATABASE_URL`, щоб він збігався з локальним паролем PostgreSQL.

Заповніть три Clerk-значення у `.env` значеннями, потрібними для вашого магазину. Публічний ключ починається з `pk_`, секретний — зі `sk_`. Не надсилайте їх у чат і не додавайте у GitHub.

Створіть таблиці в новій порожній базі:

```powershell
pnpm run local:db:init
```

Не запускайте цю команду для бази, де вже є потрібні дані.

## Запустити сайт

```powershell
pnpm run local:dev
```

Відкрийте `http://localhost:5173`. Щоб зупинити обидва сервери, натисніть `Ctrl+C` у терміналі.

У VS Code ті самі команди доступні через **Terminal → Run Task**.

## Захист коду й даних

- `.env` містить паролі й ключі — він виключений із Git.
- Не завантажуйте файл експорту бази, резервні копії чи дані замовлень у GitHub.
- Зберігайте приватну базу окремо від папки проєкту.
- Локальний запуск вимикає автоматичне оновлення товарів, щоб не змінити імпортовані дані.

## Публічний сайт з домашнього ПК

Поточні кроки не роблять магазин доступним покупцям. Для постійного публічного сайту ще потрібні HTTPS, налаштування DNS/роутера або захищений тунель, автоматичний запуск після перезавантаження ПК та резервне копіювання. Якщо інтернет-провайдер використовує CGNAT, пряме підключення може бути неможливим. Не відкривайте PostgreSQL-порт в інтернет.

Перенесення робочої бази з Replit — окремий крок. Файл міститиме особисті дані покупців, тому його треба передавати лише напряму на ваш ПК, не через GitHub.
